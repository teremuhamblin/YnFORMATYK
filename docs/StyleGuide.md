# 🎨 Styleguide
>YnFOR

Ce document définit les normes visuelles, rédactionnelles et structurelles du projet YnFOR.

---

1. Identité visuelle

Couleurs principales
- Bleu #1E88E5
- Gris #2E2E2E
- Blanc #FFFFFF

Typographie
- Titres : Roboto Bold
- Corps : Roboto Regular

---

2. Rédaction

Ton
- Professionnel
- Clair
- Direct
- Sans jargon inutile

Règles
- Titres courts
- Paragraphes concis
- Utilisation de listes pour la lisibilité

---

3. Structure des documents

Modèle recommandé
`

Titre

Sous-titre

Section
- Liste
- Liste
`

---

4. Style du code

- Utiliser des blocs markdown ou code
- Syntaxe claire
- Commentaires utiles uniquement

---

5. Normes graphiques

- Icônes simples
- Pas de surcharge visuelle
- Préférence pour SVG
`
