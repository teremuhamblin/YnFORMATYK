# 🛠️ Installation
>YnFOR
Ce guide explique comment installer et configurer YnFOR.

---

1. Prérequis
- Git
- Environnement Linux / macOS / Windows
- Node.js (si applicable)
- Accès au dépôt YnFOR

---

2. Cloner le projet
```bash
git clone https://github.com/teremuhamblin/YnFOR.git
cd YnFOR
```

---

3. Installation des dépendances
```bash
npm install
```
ou
```bash
pip install -r requirements.txt
```
- (selon la technologie utilisée)

---

4. Configuration
>Créer un fichier .env :
```md
ENV=production
API_KEY=xxxx
```

---

5. Lancer le projet
```bash
npm start
```
ou
```bash
python main.py
```

---

6. Vérification
- Le projet démarre sans erreur  
- Les logs s’affichent correctement  
- Les modules se chargent  
`
