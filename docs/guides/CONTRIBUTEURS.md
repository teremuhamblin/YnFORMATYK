# 🤝 Guide des Contributeurs
>YnFOR
Merci de votre intérêt pour contribuer à YnFOR.

---

## 1. Règles de contribution

- Lire `CONTRIBUTING.md`
- Respecter le `CODE_OF_CONDUCT.md`
- Utiliser des branches propres
- Suivre les conventions de commit

---

## 2. Processus de contribution

1. Fork du projet  
2. Création d’une branche  
3. Développement  
4. Tests  
5. Pull Request  
6. Revue  
7. Merge  

---

## 3. Branches

- `main` : stable  
- `dev` : développement  
- `feature/*` : nouvelles fonctionnalités  
- `fix/*` : corrections  

---

## 4. Style de code

- Clair  
- Documenté  
- Testé  

---

## 5. Communication

- Issues pour les bugs  
- Discussions pour les idées  
- PR pour les changement
