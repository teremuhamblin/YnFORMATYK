Plugins YnFOR

Extensions dynamiques • Hooks avancés • Système modulaire

🔌 Présentation

Le système de plugins YnFOR permet d’étendre le framework avec des fonctionnalités dynamiques, isolées, sécurisées et auto‑détectées.

🧩 Structure d’un plugin

plugin/
 ├── plugin.json
 ├── init.sh
 ├── hooks/
 │     ├── pre-run.sh
 │     ├── post-run.sh
 │     └── fail-run.sh
 └── assets/

⚙️ Fonctionnalités

  • Activation/désactivation via ynfor.conf
  • Hooks avancés (pre-run, post-run, async-run)
  • Plugins externes (GitHub, URL, registry)
  • Permissions internes (safe-mode)
  • Plugin Manager intégré
