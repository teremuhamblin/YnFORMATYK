Monitoring & Telemetry

Analyse temps réel • Dashboards • Alerting

📡 Présentation

YnFOR embarque un système de monitoring cyber‑physique permettant de suivre en temps réel l’état du framework, ses performances, ses modules et ses plugins.

📊 Métriques collectées

  • CPU / RAM
  • Modules chargés
  • Plugins actifs
  • Temps d’exécution
  • Erreurs détectées
  • Événements système

🖥️ Dashboards

  • Dashboard CLI (TUI)
  • Dashboard Web (SPA)
  • Graphiques dynamiques
  • Mode Live Telemetry

🚨 Alerting

  • Webhooks
  • Email
  • GitHub Issues automatiques
