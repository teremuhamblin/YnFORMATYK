InfraCORE

Le cœur cyber‑physique du framework YnFOR

🧬 Présentation

InfraCORE est le moteur interne de YnFOR. Il orchestre la validation, le chargement, l’exécution et la supervision du framework. Il garantit une structure propre, cohérente, modulaire et sécurisée.

⚙️ Composants

  • validator.sh — Vérifie la structure du projet
  • loader.sh — Charge modules, plugins et configurations
  • runtime.sh — Exécute le pipeline YnFOR
  • logger.sh — Logs stylés (INFO / STEP / OK / ERROR)

🚀 Pipeline InfraCORE

Validator → Loader → Runtime → Monitoring → IA
