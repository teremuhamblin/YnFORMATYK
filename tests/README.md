#🧪 Tests — YnFOR

Le dossier tests/ contient l’ensemble des tests unitaires et fonctionnels du projet YnFOR.  
Il garantit la stabilité, la qualité et le bon fonctionnement du code.

---

📁 Structure

- unit/ — Tests unitaires  
- integration/ — Tests d’intégration  
- e2e/ — Tests de bout en bout (si utilisés)

---

🎯 Objectifs

- Vérifier le comportement des modules  
- Prévenir les régressions  
- Assurer la fiabilité du projet  
- Documenter les comportements attendus  

---

▶️ Exécuter les tests

Depuis la racine du projet :

`bash
pytest
`

Ou en mode détaillé :

`bash
pytest -vv
`

---

📝 Bonnes pratiques

- Un fichier de test par module  
- Noms explicites : test_<fonction>.py  
- Tests courts, isolés et reproductibles  
- Ajouter des cas limites  

---

📄 Notes

Les tests sont obligatoires pour toute nouvelle fonctionnalité ou correction.
