⚡ YnFOR — Framework Modulaire, Automatisé & Augmenté (v1.0 → v8.0)
YnFOR est un framework nouvelle génération conçu pour offrir une architecture modulaire, automatisée, sécurisée et extensible.  
Il évolue de la simple structure (v1.0) à l’IA générative (v8.0), en passant par l’hyper‑automatisation, les plugins dynamiques et le monitoring temps réel.

---

🚀 Vision
Créer un framework auto‑géré, auto‑corrigé, auto‑optimisé, capable de :
- charger des modules intelligemment  
- valider sa propre structure  
- analyser sa sécurité  
- se monitorer en temps réel  
- s’étendre via plugins  
- s’améliorer via IA  

YnFOR est pensé pour les développeurs modernes qui veulent un outil rapide, propre, scalable, sécurisé et futuriste.

🧩 InfraCORE — Le Cœur du Framework
InfraCORE est le moteur interne qui orchestre tout :

✔ Validator
Vérifie la structure, les dossiers, les fichiers, les modules, les plugins.

✔ Loader
Charge automatiquement les modules, plugins, hooks et configurations.

✔ Runtime
Exécute le pipeline YnFOR avec logs avancés.

✔ Logger
Système de logs stylé (INFO / STEP / OK / ERROR).

---

🔌 Plugin System (v6.0+)
YnFOR supporte un système de plugins avancé :

- Plugins dynamiques  
- Activation/désactivation via ynfor.conf  
- Hooks avancés (pre-run, post-run, fail-run, async-run)  
- Permissions internes  
- Plugins externes (GitHub, URL, registry)  
- Plugin Manager intégré
