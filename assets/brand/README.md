# 🎨 Identité visuelle — YnFOR / Brand

Ce dossier contient **l’ensemble des éléments d’identité visuelle officiels** du projet YnFOR.  
Il centralise les logos, la bannière, les badges, la palette de couleurs et la typographie afin de garantir une cohérence graphique dans tout l’écosystème YnFOR.

---

## 🖼 Contenu du dossier

### **1. Logos**
- `logo.md` — Logo principal YnFOR (SVG)
- `logo_min.md` — Logo minimal (icône compacte)

### **2. Bannière**
- `banner.md` — Bannière GitHub officielle (SVG)

### **3. Badge**
- `badge.md` — Badge officiel YnFOR pour README et documentation

### **4. Palette**
- `palette.md` — Palette de couleurs officielle YnFOR

### **5. Typographie**
- `typography.md` — Polices et règles typographiques YnFOR

---

## 🎯 Objectif

Assurer une identité visuelle :
- cohérente  
- professionnelle  
- moderne  
- adaptée à l’informatique, l’automatisation et l’infrastructure  

Tous les projets YnFOR doivent utiliser ces éléments pour maintenir une image unifiée.

---

## 📐 Règles d’utilisation

- Ne jamais modifier les couleurs officielles sans validation interne.  
- Utiliser le **logo principal** pour les pages d’accueil et documents importants.  
- Utiliser le **logo minimal** pour les icônes, modules, miniatures.  
- Utiliser la **bannière** pour les dépôts GitHub et pages de présentation.  
- Utiliser le **badge** dans les README pour identifier un projet YnFOR officiel.  

---

## 📁 Structure recommandée

```
brand/
 ├─ logo.md
 ├─ logo_min.md
 ├─ banner.md
 ├─ badge.md
 ├─ palette.md
 └─ typography.md
```

---

## 🛠 Mise à jour

Toute évolution de l’identité visuelle doit être :
1. Documentée dans `CHANGELOG.md`
2. Validée via une Pull Request
3. Approuvée par les CODEOWNERS
