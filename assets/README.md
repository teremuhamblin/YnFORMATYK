# 🎨 Assets — YnFOR
>Le dossier `assets/` regroupe toutes les ressources statiques utilisées par le projet **YnFOR**.

# 📁 Assets YnFOR
>Ce dossier contient l'identité visuelle officielle du projet YnFOR.

## Sous-dossiers
- brand/ : logos, badges, palette, typographie
- icons/ : icônes du projet
- illustrations/ : schémas, diagrammes, visuels techniques

---

## 📁 Contenu
- **images/** — Logos, illustrations, visuels  
- **icons/** — Icônes SVG/PNG  
- **fonts/** — Polices d’écriture  
- **media/** — Vidéos, sons, animations  
- **brand/** — Identité visuelle, éléments graphiques YnFOR
- **themes** : thème global du projet

---

## 🎯 Objectif

Centraliser et organiser les ressources statiques afin de :

- maintenir une structure propre  
- éviter les duplications  
- faciliter la maintenance  
- garantir la cohérence visuelle du projet  

---

## 📝 Bonnes pratiques

- Utiliser des noms de fichiers explicites  
- Préférer les formats optimisés (SVG, WebP, PNG compressé)  
- Organiser par sous‑dossiers thématiques  
- Ne jamais stocker de fichiers inutiles ou trop lourds  
- Respecter le styleguide visuel du projet  

---

## 📄 Notes

Les ressources de ce dossier sont utilisées dans la documentation, l’interface et les modules internes du projet YnFOR.
